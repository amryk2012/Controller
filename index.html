ONE-TIME SETUP
Free Firebase setup (2 min):
1. Go to console.firebase.google.com
2. Add project → give it any name → continue
3. Left menu → Build → Realtime Database → Create Database
4. Choose Start in test mode (allows read/write for 30 days — enough to test)
5. Copy the URL shown (looks like https://myproject-default-rtdb.firebaseio.com)
6. Paste it above and press SAVE.

Also paste the same URL into WebController.cs in Unity.
